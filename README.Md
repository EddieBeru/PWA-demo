# PWA Demo

Demo simple del uso de tecnologías PWA para presentación en el curso de Programación 4. 
Demuestra que es requerido para que el navegador interprete la página como PWA y como reaccionan cuando se topan con una. 
La página se compone unicamente de un juego de PacMan; extraído de proyectos pasados, y código base para el funcionamiento del PWA.

## Stack / tecnologías
- HTML
- CSS
- JS

## Cómo correrlo
Abrir index.html.
La página fue hecha con HTML, CSS y JS puro (no frameworks), así, no se requiere instalación para correr

## Qué aprendí / notas
La implementación de PWA, configuración de Manifest y estándares en la industria para íconos.
